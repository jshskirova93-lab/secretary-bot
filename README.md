# Личный секретарь — Telegram-бот

Бот принимает задачи текстом и голосом, каждое утро присылает план на день
(с учётом Google Календаря), а вечером — итог по незакрытым делам.

## Что нужно перед запуском

1. **Токен Telegram-бота.** Напишите @BotFather в Telegram → `/newbot` →
   следуйте инструкциям → получите токен вида `123456:ABC-DEF...`.
2. **Свой Telegram user_id.** Напишите @userinfobot — он пришлёт ваш id.
   Это нужно, чтобы бот отвечал только вам.
3. **Ключ Claude API.** Зайдите на console.anthropic.com → API Keys →
   создайте ключ.
4. **(Опционально) Google Calendar.** Нужен, только если хотите, чтобы бот
   учитывал события из календаря в утреннем плане. Без этого шага бот всё
   равно работает — просто без событий календаря.

## Установка

```bash
cd secretary_bot
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

Откройте `.env` и впишите `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY`,
`OWNER_CHAT_ID`, свой часовой пояс.

## Настройка Google Календаря (опционально)

1. Зайдите на https://console.cloud.google.com/ → создайте проект.
2. Включите **Google Calendar API** (APIs & Services → Library).
3. Создайте учётные данные: APIs & Services → Credentials → Create
   Credentials → OAuth client ID → тип **Desktop app**.
4. Скачайте файл, переименуйте в `credentials.json` и положите в папку
   `secretary_bot/` (рядом с `bot.py`).
5. При первом запуске бот откроет браузер для входа в Google-аккаунт —
   это нужно сделать один раз, дальше токен сохранится сам.

Если пропустить этот раздел — бот просто не будет добавлять события
календаря в план, всё остальное работает как обычно.

## Запуск

```bash
python bot.py
```

Бот запустится и будет слушать сообщения. Напишите ему `/start` в Telegram.

## Первый запуск голосового распознавания

При первом голосовом сообщении faster-whisper скачает модель распознавания
речи (около 500 МБ) — это займёт минуту-другую, дальше всё быстро.

## Как пользоваться

- Напишите или наговорите: *"завтра в 15:00 позвонить врачу, это важно"* —
  бот сам поймёт дату, время и приоритет.
- Напишите или наговорите: *"купил кофе за 300 рублей"* — бот запишет это
  как трату (сумма, категория, описание определяются автоматически).
- `/today` — показывает список задач на сегодня с кнопками "готово".
- `/plan` — прислать план прямо сейчас, не дожидаясь утра.
- `/report` — прислать вечерний отчёт прямо сейчас (включает и траты за день).
- `/spending` — траты за сегодня. `/spending неделя` — за текущую неделю.
  `/spending месяц` — за текущий календарный месяц.
- Если написать не задачу и не трату, а вопрос (например *"что у меня важного
  сегодня?"*) — бот ответит в режиме диалога, опираясь на список открытых задач.

## Деплой (чтобы бот работал круглосуточно)

Локальный запуск работает, только пока открыт терминал/компьютер. Для
постоянной работы разверните бота на сервере — подойдёт Railway, Render
или обычный VPS. Дайте знать, если нужна помощь с деплоем — я могу
развернуть бота на Railway напрямую.

## Структура проекта

```
├── config.py                 # загрузка настроек из .env
├── database.py                # хранение задач (SQLite)
├── ai.py                       # обращения к Claude API
├── calendar_integration.py      # чтение Google Calendar
├── voice.py                      # распознавание голосовых сообщений
├── scheduler.py                   # утренний план / вечерний отчёт по расписанию
├── requirements.txt
└── .env.example
```
